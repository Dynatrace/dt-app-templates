# Getting Started with your Dynatrace App

This project was bootstrapped with Dynatrace App Toolkit.

It uses React in combination with TypeScript, to provide great developer experience.

## Available Scripts

In the project directory, you can run:

### `npm run start`

Runs the app in the development mode using the Vite dev server. A new browser window with your running app will be automatically opened.

Edit a component file in `ui` and save it. The changes are applied through hot module replacement. You may also see any errors in the console.

### `npm run build`

Builds the app for production to the `dist` folder. It bundles your app with Vite in production mode, using code splitting to optimize the build for the best performance.

### `npm run deploy`

Builds the app (with Vite and code splitting) and deploys it to the specified environment in `app.config.json`.

### `npm run create:function`

Generates a new serverless function for your app in the `api` folder.

### `npm run create:action`

Generates a new custom workflow action for your app in the `actions` folder.

### `npm run uninstall`

Uninstalls the app from the specified environment in `app.config.json`.

### `npm run update`

Updates @dynatrace-scoped packages to the latest version and applies automatic migrations.

### `npm run info`

Outputs the CLI and environment information.

### `npm run help`

Outputs help for the Dynatrace App Toolkit.
